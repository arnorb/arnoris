# Commands

What agents run in this repo. Package manager: `pnpm`.

| Purpose | Command |
| --- | --- |
| Dev server | `pnpm dev` |
| Build | `pnpm build` |
| Typecheck | `pnpm astro check` |
| Deploy (manual) | `pnpm run deploy` |

A push to `main` deploys automatically through Cloudflare Workers Builds.
