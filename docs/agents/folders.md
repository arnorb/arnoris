# Folders

Where agents write documents in this repo. Skills look these entries up by name. Create a folder or file when its first content is written.

| Entry | Path | Holds |
| --- | --- | --- |
| Notes folder | `docs/notes/` | Research notes, questionnaires and other working notes |
| Plans folder | `docs/plans/` | Pitches, sprint folders and other planning documents that come before a spec |
| Discovery folder | `docs/discovery/` | Interview snapshots, opportunity trees, job statements, assumption tests |
| Coding standards | `docs/coding-standards.md` | How code is written here: `code-review` reads it, `retro` records changes to it |

Specs and tickets go where `issue-tracker.md` says, not here.
